# S7.6 — Observabilidad en pruebas y definición de terminado

> **Estado:** pendiente · **Etapa 7 — Observabilidad completa** · **Tamaño:** S · **Repos:** faclab-core, faclab-invoicing · **Brechas:** —

## 1. Identificador y título

`S7.6` — Observabilidad en pruebas y definición de terminado

## 2. Objetivo verificable

Las pruebas de integración de los flujos críticos verifican spans, atributos, correlación y logs; la plantilla de PR incluye la definición de terminado de observabilidad.

## 3. Problema que resuelve

Sin pruebas, la instrumentación se degrada en silencio con cada cambio.

## 4. Evidencia de la brecha actual

- Las pruebas actuales desactivan OTel (`tests/conftest.py:9`) y no verifican telemetría.

## 5. Componentes y archivos que probablemente se modificarán

- Fixtures de exportadores en memoria en ambos repos, pruebas de flujos críticos, plantillas de PR.

## 6. Archivos o módulos que deben inspeccionarse antes de editar

- OBSERVABILITY.md §10, pruebas existentes de POS, outbox y facturación.

## 7. Dependencias y sesiones previas

[S7.1](S7.1-metricas-del-core.md), [S7.2](S7.2-metricas-de-facturacion.md)

## 8. Tareas concretas en orden

1. Crear fixtures reutilizables de exportador de spans, lector de métricas y captura de logs.
2. Escribir pruebas para venta POS, outbox, consumo de `invoices`, emisión de factura y webhook.
3. Agregar la definición de terminado a las plantillas de PR (crear la de invoicing si no existe).

## 9. Criterios de aceptación verificables

- Quitar un span crítico o romper la correlación hace fallar una prueba.
- Las plantillas de PR incluyen la lista de observabilidad.

## 10. Pruebas que deben ejecutarse

- faclab-core: `make lint && make typecheck && .venv/bin/python -m pytest tests/ -q`
- faclab-core: `make test-integration` si cambian modelos, migraciones, consultas SQL o flujos con PostgreSQL
- faclab-invoicing: `npm run lint && npm run typecheck && npm test`
